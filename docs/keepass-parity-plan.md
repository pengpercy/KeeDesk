# KeePass 2.x 功能完善计划

以原版 [KeePass 2.x 官方功能对照](https://keepass.info/compare.html) 和 KeeDesk v1.2.1 为基线。按数据风险、现有操作的可用性和功能覆盖面依次推进。每项通过验收后勾选。

## P0 · 保护现有数据与凭证

- [x] **本地保存冲突检测**。保存前检查磁盘内容，发现外部修改或删除时提示另存为。关闭标签页或退出时保留未保存的会话。锁定时尝试将更改写入应用数据目录中的加密恢复副本，并在最近打开中提供入口。已验证同时间戳内容变更、双进程保存、另存为、恢复副本和加密写入失败。若原路径和恢复目录都无法写入，自动锁定仍会执行并报告未保存。
- [x] **禁止静默降级自动输入保护**。已移除无效开关。KDBX 中已有的双通道混淆标记会保留，遇到要求混淆的条目时提示并停止自动输入。

## P1 · 补齐日常工作流

- [x] **本地密码库双向同步和冲突恢复**。文件菜单及工作区菜单已提供双向同步与单向合并。两份文件保留各自的密钥和加密设置。条目内容按最后修改时间合并，位置按移动时间处理。修改时间相同且内容不同，以发起同步的密码库为准，另一版进入历史。已验证不同密钥、移动、删除、历史、图标、重复同步、外部文件变化和第二份写入失败后的原文件恢复。进程在两次写回之间被强制终止时，第一份原始加密文件保留在同目录的 `KeeDesk-Sync-Recovery-*.kdbx`，可手动恢复。同机锁协调 KeeDesk 进程，外部应用及跨设备并发随多人编辑验收。 [原版同步](https://keepass.info/help/v2/sync.html)
- [x] **高级查找与审计**。支持跨字段组合关键词、引号短语、排除词、正则和 XPath，保留过期和回收站筛选。XPath 支持历史快照、附件名称、分组备注及 `kp:matches` 和 `kp:string-compare`。查找配置可保存、更新和删除，存放在当前加密密码库内。安全审计按需查找相似密码，以 75% 为阈值，为每个命中的条目列出最相近的另一条，完全相同的密码由重复密码检查处理。已验证查询条件、配置写入失败回滚、检测范围与取消。 [原版搜索](https://keepass.info/help/base/search.html)
- [ ] **自动输入兼容**。已实现跨库匹配、窗口关联自定义序列、常用占位符、按位置取字符和可自定义全局热键。macOS 已验证热键注册、更换和释放，Windows 与 Linux X11 的桌面实际发键仍待验收。Wayland 通过兼容的桌面合成器与 `wtype` 提供手动自动输入。要求双通道混淆的条目仍会停止执行，需实现并验证保护后才开放。 [原版自动输入](https://keepass.info/help/base/autotype.html)
- [x] **HTTPS/WebDAV 与网盘密码库**。HTTPS/WebDAV 使用本地加密工作副本，可离线编辑。写回要求服务器提供强 ETag，遇到并发更新会重新下载、合并并重试。Google Drive、Microsoft OneDrive、Dropbox 和 iCloud Drive 通过桌面客户端的同步目录打开或双向合并。文件被客户端更新后，可选择同一文件合并尚未保存的更改。网盘客户端负责云端传输，KeeDesk 校验本机可见的文件版本。已验证模拟 WebDAV 并发写入、离线、本地同步目录识别和同文件合并。 [原版多人编辑](https://keepass.info/help/base/multiuser.html)
- [x] **迁移、打印与导出首批**。CSV 支持字段映射、导入预览、常用分隔符和嵌套分组。支持迁移 KeePass 1.x AES 和 Twofish 密码库，已用 KeePassXC 的真实旧库样本验证，覆盖 Windows-1252 密码。新增表格和逐条详情的可打印 HTML，以及基于 KeePass XML 的 XSLT 1.0 导出。 [原版导入导出](https://keepass.info/help/base/importexport.html)
- [ ] **附件查看与编辑**。先增加常见图片和纯文本的内置预览，再增加文本编辑，保留现有导出入口。验收覆盖损坏附件、编辑撤销和保存后重新打开。

## P2 · 平台与扩展能力

- [ ] **网盘直连**。优先评估 Google Drive 和 Microsoft OneDrive 的账号授权、离线行为和条件写入，再扩展其他网盘。
- [ ] **扩展迁移格式**。按用户常用的来源补充原生导入并验证字段保真。
- [ ] **平台安全能力**。逐平台验证安全输入、防截屏、内存保护和无障碍使用。Windows 安全桌面与其他平台的保护能力分别验收。
- [ ] **自动化与扩展**。先定义受控的触发器和脚本权限，再评估浏览器集成、Passkeys、硬件密钥与插件接口。验收覆盖权限边界、禁用和撤销。 [原版插件目录](https://keepass.info/plugins.html)
